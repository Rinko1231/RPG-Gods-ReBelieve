# RPG Gods 1.20.1 — Data Pack Wiki

This wiki documents the **Forge 1.20.1** data pack format of RPG Gods. The mod
itself adds almost nothing on its own: deities, altars, offerings, sacrifices,
perks, favor values and patron rules all come from data packs.
